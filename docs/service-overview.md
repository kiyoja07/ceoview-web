# 경영한눈 서비스 안내서 (비개발자용)

이 문서는 **개발 지식이 없는 분**이 경영한눈([ceoview.kr](https://ceoview.kr))이 어떤 서비스이고,
화면에서 무엇을 할 수 있으며, 화면 뒤에서는 무슨 일이 일어나는지 이해하기 위한 문서입니다.

문서는 크게 두 부분으로 나뉩니다.

| 구분 | 뜻 | 쉽게 말하면 |
| --- | --- | --- |
| **프런트엔드** | 사용자가 눈으로 보고 클릭하는 화면 | "무엇이 보이고, 무엇을 누를 수 있나" |
| **백엔드** | 화면 뒤에서 데이터를 처리·저장·발송하는 부분 | "버튼을 누르면 뒤에서 무슨 일이 일어나나" |

---

## 1. 한 줄 요약

> **세무대리인이 쓰던 세무 프로그램(위하고)의 엑셀을 그대로 올리면,
> 거래처 사장님과 그 회사 직원들이 각자 자기 화면에서 급여·재무 정보를 확인할 수 있게 해주는 서비스.**

세무대리인은 시스템을 직접 개발하지 않고도 "우리 사무실이 제공하는 고객용 시스템"을 거래처에 줄 수 있고,
사장님은 엑셀·카톡으로 결과물을 받는 대신 대시보드에서 직접 보고,
직원은 급여명세서를 자기 포털에서 확인합니다.

---

## 2. 사용자는 세 부류입니다

| 사용자 | 하는 일 | 접속 주소 |
| --- | --- | --- |
| **세무대리인** (세무사 사무실) | 거래처 등록, 급여 엑셀 업로드, 재무리포트 생성·게시 | `agent.` 로 시작하는 주소 |
| **회사** (사장님 / 급여 담당자) | 급여 대장·재무리포트 확인, 지급 대상자 관리, 명세서 발송 | `company.` 로 시작하는 주소 |
| **급여 수령자** (직원) | 본인 급여명세서 확인, 계좌·개인정보 수정 | `employee.` 로 시작하는 주소 |

세 사용자는 **주소부터 완전히 분리**되어 있습니다. 같은 서비스지만 서로의 화면에 들어갈 수 없고,
로그인 정보도 따로 관리됩니다. (누구나 볼 수 있는 홈페이지·예시 화면은 주소 앞에 아무것도 붙지 않습니다.)

# 프런트엔드 — 사용자가 보는 화면

## 3. 로그인하지 않아도 볼 수 있는 화면

### 3-1. 홈페이지 (서비스 소개)

위에서부터 순서대로 이런 내용이 펼쳐집니다.

1. **첫 화면** — "이제 거래처에 당당하게 시스템까지 제공하세요" + [급여 시스템 예시 화면 보기] 버튼
2. **세무대리인께 드리는 말씀** — 왜 필요한지 4가지 이유
3. **데이터 연동 설명** — 위하고에서 작업 → 엑셀 다운로드 → 경영한눈에 업로드, 3단계
4. **사장님께 드리는 말씀** — 결과물만 받지 말고 직접 확인하세요
5. **명세서 발송 소개** — 클릭 한 번으로 전 직원 발송
6. **후기 / 사용자별 시작하기 카드 / 요금 / 자주 묻는 질문**

화면 맨 위 메뉴에서 "세무대리인으로 시작하기 / 급여 담당자로 시작하기 / 급여 수령자로 시작하기" 중
본인에게 맞는 입구를 고르면 됩니다.

### 3-2. 예시 화면 (쇼케이스)

가입하지 않아도 **서비스가 어떻게 생겼는지 전체를 훑어볼 수 있는 읽기 전용 페이지**입니다.
세무대리인 화면 → 회사 화면 → 급여 대장 → 직원 포털 → 급여명세서 순으로 샘플 데이터가 보여집니다.
버튼을 눌러도 실제로 저장되거나 발송되지 않습니다. 거래처 사장님께 서비스를 소개할 때 쓰기 좋습니다.

### 3-3. 급여명세서 열람 링크

직원이 이메일·문자·알림톡으로 받은 링크를 누르면 열리는 화면입니다.
로그인 없이 **본인 명세서 한 장만** 보이고, 그 자리에서 "직원 계정 만들기"로 이어질 수 있습니다.
(링크는 유효기간이 있고 1회만 열립니다. 아래 백엔드 6-5 참고)

---

## 4. 세무대리인 화면

### 메뉴 구성

`거래처 목록` · `재무리포트` · `설정`

### 4-1. 시작하기

1. 이메일을 입력하면 **로그인 링크**가 메일로 옵니다. (비밀번호 없음)
2. 처음이라면 계정이 자동으로 만들어집니다.
3. 우리 세무사무실 정보(사업자번호·상호·대표자·연락처)를 등록합니다. 이것이 **소속 조직**이 됩니다.
4. 같은 사무실 직원은 초대 링크로 합류시킬 수 있습니다. (`설정 > 회사 사용자`)

### 4-2. 거래처 등록

`거래처 목록 > 새 거래처`에서 **사업자등록번호**를 입력하면
국세청 조회로 실제 사업자인지 자동 확인되고, 상호·개업일 같은 정보가 채워집니다.
등록이 끝나면 그 거래처의 사장님에게 초대(이메일 또는 문자)를 보낼 수 있습니다.

### 4-3. 거래처 개요

거래처 하나를 누르면 요약 카드가 보입니다.

- **재무리포트**: 저장된 리포트 몇 건 / 그중 공개(게시)된 건 몇 건
- **거래처 사용자**: 이 회사에 연결된 사용자 수, 활성/마스터 수

### 4-4. 재무리포트 만들기 (핵심 기능)

`거래처 > 재무리포트 > 리포트 생성` 화면에서 두 단계로 진행합니다.

1. **계정과목 매핑 올리기** — 위하고 계정과목을 표준 계정과목으로 바꿔주는 대조표(CSV/엑셀).
   한 번 올리면 다음부터 목록에서 골라 재사용합니다.
2. **분개장 올리기** — 위하고에서 받은 분개장 엑셀(.xls/.xlsx)을 그대로 올립니다.

올린 뒤 선택지는 세 가지입니다.

- **미리보기** — 저장하지 않고 결과만 확인
- **생성 및 저장** — 내 쪽에만 저장 (거래처는 아직 못 봄)
- **게시** — 거래처가 볼 수 있게 공개

같은 파일을 또 올리면 "이미 저장된 분개장입니다"라고 경고하고, 원하면 기존 것을 대체합니다.

### 4-5. 설정

`회사 정보`(우리 사무실 정보) · `회사 사용자`(직원 초대·권한) · `내 정보`

## 5. 회사(사장님·급여 담당자) 화면

### 메뉴 구성

`대시보드` · `인건비` · `재무리포트` · `지급 대상자` · `설정`

### 5-1. 시작하기

- 세무대리인이 보낸 **초대 링크**로 들어오거나, 직접 가입할 수 있습니다.
- 이메일로 오는 **로그인 링크**로 들어갑니다. (비밀번호 없음)
- 처음이면 사업자 정보를 입력하는 **온보딩** 화면이 뜹니다.
  사업자번호를 입력하면 국세청 조회로 상호·대표자가 자동으로 채워집니다.
- 이미 등록된 회사에 합류하려는 경우에는 **가입 요청 → 승인 대기** 상태가 되고,
  기존 담당자나 세무대리인이 승인하면 들어갈 수 있습니다.
- 한 사람이 **여러 회사**에 속해 있으면 화면 위에서 회사를 전환할 수 있습니다.

### 5-2. 대시보드

- 회사 기본 정보와 연결된 세무대리인
- 인건비 요약 / 지급 대상자 요약 / 재무리포트 요약
- 바로가기 카드: 재무리포트 보기, 인건비 내역 보기, 지급 대상자 관리, 회사 정보 관리
  (지급 대상자 **등록** 카드는 현재 노출 보류 상태이며, `지급 대상자` 메뉴 안에서는 등록할 수 있습니다)

### 5-3. 인건비 (급여 대장)

**귀속년월 / 지급년월**을 고른 뒤 조회합니다. 화살표 버튼으로 전·다음 달로 바로 이동할 수 있습니다.

- 위쪽에 **합계 카드**(지급액·공제액·실수령액 등)
- 아래에 소득 종류별 카드 4개 — **근로소득 · 사업소득 · 일용소득 · 기타소득**
- 카드를 누르면 해당 소득의 상세 대장(사람별 표)으로 이동
- 맨 아래 **월별 통계 차트** (12개월/기간 선택 가능)

상세 대장 화면에서 할 수 있는 일:

- 직원 한 명의 **급여명세서 미리보기** (팝업)
- **명세서 발송** — 이메일 / 문자 / 카카오 알림톡 중 선택, 한 명씩 또는 전 직원 일괄
- **명세서 일괄 다운로드** — 전 직원 명세서를 PDF로 만들어 ZIP 파일 하나로 내려받음
- 근로소득의 경우 원천징수영수증 형태의 표도 확인
- 일괄 발송은 진행률(몇 명 중 몇 명)이 표시되고, 끝나면 성공·실패·연락처 없음 인원이 집계됩니다

### 5-4. 재무리포트

세무대리인이 **게시**한 리포트만 보입니다. 게시 전이면 "아직 없음"으로 표시됩니다.

- 상단 요약: 회계연도, 거래 건수, 수익 합계, 비용 합계, 거래액
- 차트: 월별 수익·비용, 현금 유입·유출, 월별 순증감, 누적 순증감
- 표(누르면 상세 화면으로):
  1. 수익 by 계정 / 수익 by 거래처
  2. 비용 by 계정 / 비용 by 거래처
  3. 부가세 (매출세액·매입세액)
  4. 현금 유입 / 현금 유출 (상대 거래처 기준)

모든 표는 **월별 열 + 합계 열**로 된 가로형 표(피벗)입니다.

### 5-5. 지급 대상자

급여를 받는 사람들의 명단입니다. 이름·사원코드·부서·연락처로 검색할 수 있고,
소득 종류별로 등록 양식이 다릅니다 (근로 / 사업 / 기타 / 일용).
등록할 때 주민등록번호·주소·계좌 같은 항목은 전용 입력창을 통해 형식이 자동으로 맞춰집니다.

### 5-6. 설정

`내 정보` · `회사 정보` · `회사 사용자`(초대, 가입 요청 승인/거절)

---

## 6. 직원(급여 수령자) 화면

### 메뉴 구성

`홈` · `급여 명세서` · `내 정보`

### 6-1. 시작하기

두 가지 경로가 있습니다.

- 회사에서 보낸 **급여명세서 링크**를 열고 그 자리에서 계정 만들기
- 직원 로그인 화면에서 **등록된 이메일 또는 전화번호**를 넣고 로그인 링크 받기

### 6-2. 홈

- "○○○님" 인사와 회사·부서·직급
- **최근 급여 카드** — 지급액 / 공제액 / 실수령액, [상세보기] 버튼
- 본인 정보(연락처·주소)와 **급여 입금 계좌**를 직접 수정할 수 있습니다

명세서가 아직 공개되지 않았으면
"확인 가능한 급여명세서가 없습니다 — 회사 담당자에게 문의해 주세요"라고 안내합니다.

### 6-3. 급여 명세서

월별 목록에서 원하는 달을 고르면 그 달 명세서를 봅니다.
**공개된 급여 자료 중 본인 것만** 보이며, 다른 사람 명세서는 절대 보이지 않습니다.

## 7. 화면 공통 규칙 (UX)

- **비밀번호가 없습니다.** 모든 로그인은 이메일(또는 문자)로 받는 1회용 링크 방식입니다.
- **로딩 / 오류 / 비어 있음** 상태가 화면마다 정해져 있습니다. 오류에는 [다시 시도] 버튼이 붙습니다.
- **PC와 모바일 모두** 대응합니다. 직원 포털은 특히 휴대폰에서 보기 좋게 만들어져 있습니다.
- 사업자번호·주민등록번호·전화번호·계좌번호는 **전용 입력창**이 있어 형식이 자동으로 정리됩니다.
- 중요한 동작(게시, 삭제, 발송)은 **확인 팝업**을 한 번 거칩니다.
- 화면에 보이는 모든 안내 문구는 한국어이며, 실무에서 쓰는 용어(귀속년월, 지급년월, 공제액계 등)를 그대로 씁니다.

# 백엔드 — 화면 뒤에서 일어나는 일

## 8. 로그인과 본인 확인

| 항목 | 내용 |
| --- | --- |
| 방식 | 매직 링크 (이메일/문자로 보내는 1회용 로그인 링크) |
| 링크 유효시간 | 세무대리인: 설정값 / 회사: 30분 / 직원: 15분 |
| 링크 재사용 | **불가** — 한 번 쓰면 사용 처리됨 |
| 로그인 유지 | 약 **14일** (그 뒤에는 다시 링크를 받아야 함) |
| 추가 확인 | 가입·정보 수정 시 **휴대폰 인증번호** 확인 절차가 있음 |

링크 원본은 서버에 저장되지 않습니다. **암호화된 지문(해시)만** 저장해 두고 대조하는 방식이라,
데이터베이스가 유출되더라도 그 값으로 로그인할 수 없습니다.

## 9. 권한과 데이터 분리

- 모든 데이터 조회는 "**이 사람이 이 회사에 속해 있는가**"를 서버에서 먼저 확인합니다.
- 세무대리인은 **자기 조직에 연결된 거래처**만, 회사 사용자는 **자기 회사**만,
  직원은 **본인 자료**만 볼 수 있습니다.
- 주소를 직접 쳐서 남의 회사 번호를 넣어도 서버가 막습니다(권한 없음 처리).
- 삭제한 자료는 실제로 지우지 않고 "삭제 표시"만 해서, 실수로 지웠을 때 복구할 여지를 남깁니다.

## 10. 급여 엑셀 업로드 처리

1. 세무대리인이 위하고에서 받은 엑셀을 올립니다.
2. 서버가 **소득 종류(근로/사업/기타/일용)에 맞는 해석기**를 골라 표를 읽습니다.
   엑셀 양식이 조금씩 달라도 대응할 수 있게 종류별로 여러 해석 방식이 준비되어 있습니다.
3. 필수 항목이 빠졌으면 **저장하지 않고 오류**를 돌려줍니다.
4. 문제가 없으면 사람별 금액(기본급·상여·식대·4대보험·소득세 등)으로 쪼개 저장합니다.
5. 업로드 이력이 남아, 언제 누가 어떤 파일을 올렸는지 확인할 수 있습니다.
6. 같은 파일을 또 올리면 **파일 지문(체크섬)으로 중복을 감지**합니다.

## 11. 재무리포트 생성 처리

1. **계정과목 매핑표**를 읽어 "위하고 계정과목 ↔ 표준 계정과목, 수익/비용 여부, 부가세 여부"를 파악합니다.
2. **분개장**을 읽어 차변·대변 거래를 짝지어 정리합니다.
3. 정리된 거래로 7가지 표(수익 by 계정/거래처, 비용 by 계정/거래처, 부가세, 현금 유입/유출)를
   **월별 피벗 형태**로 계산합니다.
4. 계산 결과 요약은 따로 저장해 두어, 나중에 화면을 열 때 빠르게 뜨게 합니다.

## 12. "게시(공개)" 구조 — 가장 중요한 개념

경영한눈에는 **저장**과 **게시**가 나뉘어 있습니다.

| 상태 | 세무대리인 | 거래처·직원 |
| --- | --- | --- |
| 저장됨 | 볼 수 있음 (본인이 올린 것) | **못 봄** |
| 게시됨 | 볼 수 있음 | 볼 수 있음 |

- 검토가 끝난 자료만 공개할 수 있게 하는 안전장치입니다.
- **한 거래처에 "지금 공개 중인 자료"는 소득 종류별로 1건, 재무리포트도 1건**뿐입니다.
  새 자료를 게시하면 이전 게시물은 자동으로 내려갑니다.
- 직원이 보는 명세서도 "현재 게시 중인 급여 자료" 기준입니다.
- 세무대리인이 거래처의 급여 화면을 열면 게시 전 자료도 보이지만, **본인이 올린 것만** 보입니다.

## 13. 급여명세서 발송

발송 버튼을 누르면 서버가 순서대로 처리합니다.

1. 받는 사람의 연락처를 확인합니다. **이메일이 있으면 메일, 전화번호가 있으면 문자·알림톡**이 가능합니다.
   연락처가 없는 채널은 자동으로 제외됩니다.
2. 그 사람 전용 **1회용 열람 링크**를 만듭니다.
   - 유효기간 **72시간**, **1회 열람** 후 만료
   - 링크 주소로는 누구인지 알 수 없는 무작위 값 사용
3. 이메일은 명세서 내용이 본문에 직접 들어가고, 문자·알림톡은 요약 금액 + 링크가 갑니다.
4. 발송 결과(성공/실패, 채널, 받는 사람, 시각)를 기록합니다. 실패 사유도 남습니다.

## 17. 지금은 화면에서 빠져 있는 것 (기능은 만들어져 있음)

개발은 되어 있지만 **현재 메뉴에서 접근할 수 없도록 숨겨 둔** 부분입니다.

- 세무대리인 화면의 **직원 현황 / 급여 현황** 메뉴
- 세무대리인 화면의 **거래처별 직원 탭 / 급여 탭** (급여 엑셀 업로드 화면 포함)
- 세무대리인의 **지급 대상자 개별 등록** 화면

즉, 지금 세무대리인 화면에서 실제로 쓸 수 있는 것은
**거래처 등록·관리, 재무리포트 생성·게시, 사용자·설정**입니다.
회사와 직원 화면은 급여 관련 기능까지 모두 열려 있습니다.

## 18. 요금

- 홈페이지 안내: **현재 전 기능 무료** (세무대리인 0원 / 거래처 0원)
- 코드 안에는 향후 유료 요금제(Starter·Growth·Enterprise) 정의가 준비만 되어 있고,
  실제 결제는 적용되어 있지 않습니다.
- 유료 전환 시 부과 예정으로 검토 중인 항목: 급여 일괄 입금, 동일 월/직원 명세서 재발송 횟수 제한
